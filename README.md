## 📖 Overview

MoodSync v1 is an intelligent music recommendation system that suggests songs based on the user's current mood and preferred language. The system combines lightweight Natural Language Processing (NLP), basic Machine Learning, and a structured music dataset to provide personalized recommendations through an easy-to-use web interface.

Unlike traditional music recommendation systems that rely only on listening history, MoodSync v1 focuses on understanding the user's present emotional state and recommending songs accordingly.

The project was developed as an academic implementation of Machine Learning, Web Development, and Recommendation System concepts.

# 🤖 Recommendation Engine

The recommendation system follows a simple content-based filtering approach.

Recommendations are generated by:

- Detecting the user's mood.
- Filtering songs belonging to the detected mood.
- Applying language filtering.
- Randomly selecting songs to improve recommendation diversity.

This lightweight recommendation strategy enables fast response time while maintaining relevant results.

# 🌐 Deployment on Render

MoodSync v1 is optimized for deployment on Render.

Deployment Steps

1. Push the project to GitHub.
2. Create a new Web Service on Render.
3. Connect the GitHub repository.
4. Render automatically detects `render.yaml`.
5. Deploy the application.

The deployment uses:

- Python 3.10
- Gunicorn
- Flask
- Render Free Tier

Health Check Endpoint

```
/ping
```
